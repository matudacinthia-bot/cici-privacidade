# Para que serve esta página

O Google só deixa um app OAuth sair do modo "Testando" para produção quando a tela de Branding do Google Auth Platform tem uma "Página inicial do aplicativo" e um "Link da Política de Privacidade". Em modo de teste, a autorização da CICI na conta Google da Cinthia vence a cada 7 dias.

Esta página cumpre os dois campos com a mesma URL:

https://matudacinthia-bot.github.io/cici-privacidade/

Onde usar: Google Cloud Console, projeto hermes-cinthia, Google Auth Platform, Branding.

Ao mudar os escopos do app (Gmail, Agenda, Drive, Contatos, Planilhas, Documentos), atualize a lista na página e a data de atualização.
